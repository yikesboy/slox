# slox

`slox` is a small interpreter for the Lox language from Crafting Interpreters, written in Swift.

It supports running a `.lox` script file or starting a REPL.

## Requirements

- Swift 6.1 or newer

## Run

Build the project:

```sh
swift build
```

Start the REPL:

```sh
swift run slox
```

Run a script file:

```sh
swift run slox path/to/script.lox
```
